# PrintGrid Pro official downloads

This is the official Windows installer distribution repository for **PrintGrid Pro**, published and maintained by **Artwork Lab LLC**.

Artwork Lab LLC authorizes this repository, `https://github.com/nidjooo/printgrid-downloads`, as an official download source for PrintGrid Pro Windows release packages.

- Official website: https://printgridpro.com/
- Windows desktop app and download information: https://printgridpro.com/desktop
- Microsoft Store: https://apps.microsoft.com/detail/9NGZ7VZ7M9H2
- Release downloads: https://github.com/nidjooo/printgrid-downloads/releases
- Support: support@printgridpro.com

This repository distributes released installers only. Application source code is not included. Refer to each release for its version and package details.
